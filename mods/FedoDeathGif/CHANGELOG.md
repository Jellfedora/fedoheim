# Changelog

## 1.0.0

- The instant you die, posts a short gif of your last moments to a Discord channel via
  a webhook — no external recording software needed.
- Shows an on-screen death message and makes your character shout a line in chat.
- Gif resolution, frame rate, recording length, and every message are configurable —
  the admin's values apply to everyone, except the webhook URL, which stays private to
  each install.

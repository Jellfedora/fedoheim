# Changelog

## 1.0.0

- New mod, built for Valheim 1.0. Adds a color picker next to a sign's text input
  window — a saturation/brightness square, a hue bar, a hex code field, and quick
  swatches — instead of typing a color code by hand.
- Reopening a sign you'd already colored shows its current color instead of resetting
  to red.
- The hex code field can be selected and copied, to reuse the same color on another
  sign.

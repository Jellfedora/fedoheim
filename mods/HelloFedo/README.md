# HelloFedo

*By Fedo*

A minimal smoke-test mod: it displays a "Hello Fedo" banner at the top of the screen and does
nothing else. No configuration, no dependencies beyond BepInEx itself.

## How it works

Used to verify that BepInEx and the modpack are correctly installed and loading — if you see
the banner, plugins are loading fine. Not meant to stay in the production modpack long-term.

## Notes

- No `.cfg` file is generated — there is nothing to configure.

Expéditions
L'onglet Expéditions montre toutes les expéditions parties du <color=orange>port actuel</color>.

<color=orange><b>Détail d'une expédition</b></color>
Chaque expédition affiche :
<size=5>●</size> Les objets rangés dans chaque manifeste
<size=5>●</size> Le port d'arrivée
<size=5>●</size> L'heure d'arrivée estimée
<size=5>●</size> L'état actuel (<color=yellow>En transit</color> ou <color=yellow>Livré</color>)

<color=yellow>Note :</color> l'onglet Port résume aussi les expéditions par destination, mais seul l'onglet Expéditions montre le contenu complet de chaque manifeste.
